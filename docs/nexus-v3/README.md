# Archived Nexus V3 material

This directory preserves pre-remediation design notes and generated demonstrations for historical traceability. Its `species_safe`, `gbif_ready`, “scientific validation” and similar labels are legacy terminology and must not be treated as the current product contract or as evidence of external biological/GBIF validation.

Use the repository root `README.md`, `docs/barcode-compiler-methodology.md`, `docs/submission.md` and the current generated reports instead. The current primary states are rule-result and GBIF validation-candidate states; independent specimen-backed holdout validation and external IPT/GBIF acceptance remain outstanding.
